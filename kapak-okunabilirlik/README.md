# YouTube Kapak Okunabilirlik Testi

`index.html` dosyasını tarayıcıda aç; bir kapak görseli seç veya yükleme alanına sürükle. Küçük önizlemeleri gri tonlama, bulanıklık ve süre etiketi seçenekleriyle karşılaştır.

Önizleme boyutları yaklaşık değerlerdir, resmî ölçüler değildir. Parlaklık, kontrast ve etiket alanı analizi basit bir sezgisel kontroldür; okunabilirlik garantisi vermez.

Kurulum veya sunucu gerekmez. Uygulama çevrimdışı çalışır; görsel tarayıcıdan çıkmaz ve kalıcı olarak saklanmaz. Yalnızca YouTube Yardım bağlantısı internet gerektirir.
